# Codex project guidance

Read `CLAUDE.md` at the repository root before planning or changing this project. It is the shared source for setup, commands, conventions, and architecture rules.

- Before working under `backend/`, read `backend/CLAUDE.md`.
- Before working under `frontend/`, read `frontend/CLAUDE.md`.
- For Codex worktree setup and launch actions, read `docs/agents/codex-worktrees.md`.
- When starting or resuming a ticket, or handing off unfinished work, read `docs/agents/codex-continuity.md`.
- When an architecture guard fails, or before adding, changing, or deleting one, read `docs/agents/architecture-guards.md`, the enforcing test, and the guarded module.

Update shared project rules in those files so Claude and Codex use the same guidance.
