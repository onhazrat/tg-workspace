Brings the frontend to Vite 8, matching the upstream `full-stack-fastapi-template`, which has already moved.

Vite 8 replaces the old esbuild-for-dev plus Rollup-for-prod split with [Rolldown](https://vite.dev/blog/announcing-vite8) as a single Rust bundler, Oxc as the transformer, and Lightning CSS as the default minifier.

## Why this was low risk

Rolldown breakage concentrates in Rollup-specific plugins and esbuild transform hooks. This project has neither: no `rollupOptions`, no `esbuild` block, no `transformWithEsbuild`, no `optimizeDeps` overrides, and no postcss config. There was nothing for Vite 8's compatibility layer to translate, and **`vite.config.ts` needed no changes at all**.
